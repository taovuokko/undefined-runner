# Undefined Runner

Small endless runner game written in C++ using raylib.

Personal **C++ learning project**.  
Originally based on a course assignment, but refactored and modified along the way.

The goal is to practice:
- basic game loop
- input handling
- simple physics (jump + gravity)
- structuring C++ code cleanly

Built and tested on Linux.

---

### Build & run

Requires raylib.

```bash
make
make run
